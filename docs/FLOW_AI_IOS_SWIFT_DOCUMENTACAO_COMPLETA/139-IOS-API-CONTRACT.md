# Contrato iOS ↔ Backend
## Princípios
Consumir somente endpoints documentados no contrato oficial.

## Requisitos
DTOs tipados, versionamento, paginação, erros padronizados, nullability explícita e idempotência.

## Compatibilidade
Mudanças incompatíveis exigem versionamento/migração.

## WebSocket
Eventos devem possuir tipos e payloads documentados.
