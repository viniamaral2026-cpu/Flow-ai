# iOS Files
## Recursos
Selecionar, visualizar, enviar e baixar arquivos através das APIs modernas de documentos/arquivos do iOS.

## Segurança
Não solicitar acesso global desnecessário.

## Upload
Validar tipo, tamanho, progresso, cancelamento e retry.

## Download
Respeitar espaço disponível e localização escolhida pelo usuário quando aplicável.
