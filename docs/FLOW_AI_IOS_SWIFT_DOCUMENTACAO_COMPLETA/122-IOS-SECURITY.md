# iOS Security
## Princípios
Least privilege, Keychain, HTTPS, validação server-side e minimização de dados.

## Network
Produção usa HTTPS. Políticas de transporte seguro devem permanecer habilitadas.

## Secrets
Nenhuma API key privada de backend no app.

## Integridade
Avaliar mecanismos Apple disponíveis e controles anti-abuso conforme risco.
