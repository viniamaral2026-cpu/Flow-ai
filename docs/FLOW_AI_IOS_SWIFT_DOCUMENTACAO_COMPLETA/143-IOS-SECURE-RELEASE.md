# Secure iOS Release
## CI/CD
Build reproduzível, testes, análise, assinatura e distribuição.

## Certificados
Certificados, provisioning e credenciais devem ficar protegidos no CI.

## App Store Connect
Controlar acesso por função e menor privilégio.

## Rastreabilidade
Cada release deve estar ligada ao commit e pipeline que a produziu.
