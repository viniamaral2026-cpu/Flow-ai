# Regras para Agentes — iOS
## Antes
Ler documentação, inspecionar projeto e localizar implementação existente.

Pesquisar Xcode project/package, SwiftUI, navigation, models, repositories, API client, capabilities, entitlements, Info.plist e testes.

## Durante
Não inventar APIs, SDKs, endpoints, classes, permissões ou resultados. Não duplicar recursos.

## Depois
Testar → auditar → documentar.

## Segurança
Não expor secrets. Não alterar produção/publicar sem autorização.

## Visual
Respeitar o Design System oficial do FLOW AI.
