# iOS Local Storage
## Dados locais
Preferências, cache, rascunhos e dados temporários.

## Segredos
Tokens e credenciais devem usar Keychain.

## Banco local
Persistência estruturada pode usar SwiftData/Core Data ou outra solução aprovada. Escolher uma única estratégia por domínio.

## Fonte de verdade
Dados sincronizados oficiais permanecem no backend.
