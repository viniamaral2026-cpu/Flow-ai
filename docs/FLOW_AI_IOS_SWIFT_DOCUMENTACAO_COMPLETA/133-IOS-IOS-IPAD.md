# iPhone e iPad
## Objetivo
A mesma aplicação deve adaptar-se aos diferentes tamanhos e modos de multitarefa.

## iPad
Considerar Split View, Stage Manager quando aplicável, orientação e tamanhos de janela.

## UI
Não simplesmente esticar layouts de iPhone. Componentes devem usar layouts adaptativos.

## Testes
Cobrir tamanhos compact, regular e combinações relevantes.
