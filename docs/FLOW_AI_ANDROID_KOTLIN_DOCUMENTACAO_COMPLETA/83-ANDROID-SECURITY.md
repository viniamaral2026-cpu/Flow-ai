# Android Security
## Princípios
Least privilege, secure storage, network security, validação server-side e proteção de logs.

## Rede
HTTPS obrigatório em produção. Política de cleartext deve permanecer desabilitada salvo exceção documentada.

## Criptografia
Usar APIs/bibliotecas confiáveis do ecossistema Android.

## App integrity
Avaliar mecanismos de integridade e proteção contra ambientes comprometidos conforme risco do produto.

## Secrets
Nenhuma chave privada ou API key de backend dentro do APK.
