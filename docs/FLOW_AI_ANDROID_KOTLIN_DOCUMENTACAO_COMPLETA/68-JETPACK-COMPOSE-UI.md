# Jetpack Compose — UI
## Objetivo
Construir interface Android nativa mantendo a identidade visual oficial do FLOW AI.

## Design System
Primary #6D28FF, secondary #4DA3FF, accent #FF2E9E, dark text #11124B, gray #8A8AB0, background #F8F9FF, cards #FFFFFF, border #EEF0FF.

## Regras
Tema claro como padrão. Cards brancos, cantos arredondados, sombras suaves e gradientes apenas onde fizer sentido.

## Componentes
Botões, campos, cards, listas, bottom sheets, diálogos, chips, indicadores de voz, mensagens, estados vazios, loading e erro devem ser componentes reutilizáveis.

## Responsividade
Adaptar para telefones, tablets e diferentes densidades.
