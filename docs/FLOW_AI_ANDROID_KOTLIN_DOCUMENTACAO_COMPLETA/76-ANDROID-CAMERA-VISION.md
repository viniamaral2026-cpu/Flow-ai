# Câmera e Visão
## Uso
Captura de imagem somente mediante ação/requisito autorizado.

## Pipeline
Câmera → pré-processamento → serviço de visão/IA → resultado → UI.

## Privacidade
Não manter imagens sem finalidade definida. Exibir indicação quando a câmera estiver ativa.

## Falhas
Permissão, câmera ocupada, hardware incompatível, baixa iluminação, timeout e serviço remoto indisponível.
