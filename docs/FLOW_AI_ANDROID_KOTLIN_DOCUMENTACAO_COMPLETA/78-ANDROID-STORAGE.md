# Local Storage
## Pode ser local
Preferências, cache, rascunhos e dados temporários.

## Não armazenar em texto puro
Senhas, API keys, tokens ou segredos.

## Banco local
SQLite/Room pode ser usado para cache/offline quando necessário, com migrações versionadas.

## Fonte de verdade
Dados sincronizados oficiais pertencem ao backend.
