# Android Permissions
## Recursos
Microfone, câmera, notificações e outros recursos somente quando necessários.

## Princípios
Menor privilégio, solicitação contextual e tratamento de negação.

## Estados
granted, denied, permanently_denied, unavailable.

## Regra
Negação nunca deve causar crash. A UI deve explicar como reativar a permissão nas configurações do sistema quando necessário.
