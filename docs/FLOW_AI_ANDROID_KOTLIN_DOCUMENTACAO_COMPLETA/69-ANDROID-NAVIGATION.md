# Android Navigation
Usar navegação declarativa compatível com Jetpack Compose.

## Áreas
Home, Chat, Voz, Rotinas, Timers, Casa, Integrações, Memória, Arquivos, Saúde, Receitas, Skills, Conta e Configurações.

## Regras
Deep links devem abrir a tela correta sem quebrar autenticação. Estado de navegação não deve conter segredos.
