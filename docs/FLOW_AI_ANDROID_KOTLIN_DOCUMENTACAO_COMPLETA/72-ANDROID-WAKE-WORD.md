# Wake Word
## Objetivo
Permitir ativação por voz do FLOW AI quando o recurso estiver habilitado.

## Requisitos
- ativar/desativar;
- indicador de estado;
- consumo de bateria controlado;
- processamento local quando tecnicamente possível;
- fallback para ativação manual.

## Background
Qualquer execução em segundo plano deve respeitar as restrições e políticas do Android.

## Privacidade
Deixar claro quando o sistema está preparado para detectar a palavra de ativação.
