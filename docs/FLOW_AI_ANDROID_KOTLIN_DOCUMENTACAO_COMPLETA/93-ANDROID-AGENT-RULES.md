# Regras para Agentes — Android
## Antes
Ler documentação e inspecionar projeto.

Pesquisar Gradle, módulos, Manifest, Compose, navigation, ViewModels, repositories, services, WorkManager, Firebase e API client.

## Durante
Não inventar APIs, classes, endpoints, plugins ou resultados. Não duplicar recursos existentes.

## Depois
Executar testes, build e auditoria.

## Segurança
Não expor secrets. Não modificar produção ou publicar sem autorização.

## Visual
Respeitar o Design System oficial do FLOW AI e manter consistência com web e desktop.
