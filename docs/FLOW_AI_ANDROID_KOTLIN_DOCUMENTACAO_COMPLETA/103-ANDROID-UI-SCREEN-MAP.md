# Mapa de Telas Android
## Núcleo
Splash/boot, onboarding, login, cadastro, recuperação, Home, Chat, conversa, voz.

## Produto
Rotinas, timers, casa inteligente, integrações, memória, arquivos, saúde, receitas, Skills.

## Conta
Perfil, segurança, privacidade, assinatura, pagamentos, notificações e suporte.

## Estados
Loading, empty, error, offline, permission denied, session expired, maintenance e update required.

## Regra
O mapa Android deve reutilizar conceitos do mapa geral de telas do FLOW AI, mas permitir UX nativa.
