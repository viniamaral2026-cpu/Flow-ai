# Secure Release Android
## CI/CD
Build reprodutível, testes, análise estática, assinatura e publicação automatizada somente com credenciais protegidas.

## Keystore
Guardar em secret manager/CI seguro. Rotacionar conforme política.

## Play App Signing
Avaliar e documentar o modelo escolhido antes da produção.

## Auditoria
Toda release deve ser rastreável ao commit e ao pipeline que a produziu.
