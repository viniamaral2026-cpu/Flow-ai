# Firebase no Android
## FCM
Usar Firebase Cloud Messaging para push quando aprovado na arquitetura.

## Token
Registrar/atualizar token de dispositivo com segurança e associá-lo à sessão/conta no backend.

## Notificação
Separar mensagens de dados e notificações conforme necessidade do produto.

## Segurança
Não enviar segredos ou dados sensíveis desnecessários no payload.
