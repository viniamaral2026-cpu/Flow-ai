# Regras dos Agentes — flow-ai-ios

## Objetivo
Orientar agentes de IA e desenvolvedores automatizados neste repositório.

## Antes de codificar
- ler README;
- ler arquitetura;
- inspecionar árvore do projeto;
- pesquisar símbolos/rotas/componentes existentes;
- conferir contratos;
- verificar issues/branches quando disponíveis.

## Execução
Fazer somente mudanças necessárias. Preferir pequenas alterações verificáveis.

## Proibições
- inventar arquivos, APIs, endpoints ou bibliotecas;
- inventar resultado de build/teste;
- remover proteção de segurança sem justificativa;
- expor secrets;
- duplicar implementação;
- modificar produção sem autorização.

## Finalização
Entregar:
1. resumo;
2. arquivos alterados;
3. testes realmente executados;
4. limitações;
5. migrações/configurações necessárias;
6. documentação atualizada.

## Princípio
O agente não é autoridade sobre o produto: código, contratos, documentação e
configuração real do repositório são a fonte de verdade.
