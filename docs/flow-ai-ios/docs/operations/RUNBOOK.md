# Runbook Operacional

## Diagnóstico inicial
1. Identificar ambiente.
2. Identificar versão/commit.
3. Verificar saúde das dependências.
4. Consultar logs.
5. Reproduzir com segurança.
6. Aplicar correção ou rollback documentado.

## Não fazer
Não executar comandos destrutivos ou alterações de produção sem autorização.

## Comunicação
Registrar incidente, impacto, horário, causa conhecida, mitigação e resolução.
