# Testes Desktop

## Pirâmide
Unitários → integração → E2E → smoke → testes manuais de plataforma.

## Casos críticos
Login, logout, token expirado, chat, streaming, voz, Wake Word, notificações, tray, atalhos, offline, reconexão, upload, download, atualização e recuperação.

## Matriz
Executar em cada OS suportado e em suas arquiteturas relevantes.

## Segurança
Testar capabilities, IPC, armazenamento de tokens, CSP e comportamento com conteúdo malicioso.

## Release
Nenhuma release pública sem smoke test de instalação, inicialização, login e comunicação com API.
