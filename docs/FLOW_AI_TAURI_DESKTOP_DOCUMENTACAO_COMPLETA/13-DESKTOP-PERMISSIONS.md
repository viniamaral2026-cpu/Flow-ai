# Matriz de Permissões

## Recursos
- Microfone
- Câmera
- Notificações
- Arquivos
- Atalhos
- Inicialização
- Rede

## Regra
Solicitar somente quando necessário, explicar finalidade e permitir revogação quando o sistema operacional suportar.

## Negação
Permissão negada nunca deve causar crash. Exibir estado desabilitado e instrução para reativação.

## Privacidade
A coleta deve ser minimizada e documentada na política LGPD do FLOW AI.
