# Regras para Agentes no FLOW AI Desktop

## Antes de alterar
LER → INSPECIONAR → LOCALIZAR → PLANEJAR.

Pesquisar:
- package.json;
- src;
- src-tauri;
- capabilities;
- tauri.conf;
- rotas;
- serviços;
- stores;
- API client;
- documentação.

## Durante
EXECUTAR somente o necessário. Não criar duplicatas. Não inventar APIs, comandos, plugins, endpoints ou resultados.

## Depois
TESTAR → AUDITAR → DOCUMENTAR.

## Segurança
Ações destrutivas, publicação, produção, certificados e credenciais exigem autorização apropriada.

## Visual
Preservar o Design System oficial do FLOW AI: tema claro, branco, roxo/azul/rosa, cards arredondados, gradientes e linguagem visual já definida.

## Handoff
Entregar arquivos alterados, comportamento implementado, testes executados, limitações e próximos passos.
