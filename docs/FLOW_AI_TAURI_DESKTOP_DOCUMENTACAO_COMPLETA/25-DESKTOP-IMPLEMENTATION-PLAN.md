# Plano de Implementação

## Fase 1 — Fundação
Tauri 2, React/Vite, configuração, janela, build e ambientes.

## Fase 2 — Autenticação
Login, sessão, refresh, logout e armazenamento seguro.

## Fase 3 — Core
Dashboard, chat, navegação, API client e WebSocket.

## Fase 4 — Desktop
Tray, notificações, atalhos, startup e filesystem controlado.

## Fase 5 — Voz
Microfone, estados de voz, streaming e Wake Word conforme tecnologia aprovada.

## Fase 6 — Offline
Cache, reconexão, rascunhos e recuperação.

## Fase 7 — Distribuição
Builds Linux/Windows/macOS, assinatura, atualização e release.

## Fase 8 — Hardening
Segurança, acessibilidade, performance, testes e auditoria.

## Critério
Cada fase deve ser concluída e validada antes de ampliar o escopo.
