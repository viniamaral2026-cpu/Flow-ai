# Observabilidade Desktop

## Eventos
Startup, shutdown, login, logout, erro de rede, erro de voz, crash, atualização e falhas de integração.

## Privacidade
Telemetria deve ser mínima, documentada e configurável quando aplicável.

## Logs
Nunca registrar senhas, tokens, API keys, áudio bruto ou conteúdo sensível desnecessário.

## Diagnóstico
O usuário deve conseguir gerar relatório técnico contendo versão, OS, arquitetura e erros relevantes sem expor segredos.
