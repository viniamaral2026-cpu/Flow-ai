# Cache e Dados Locais — Especificação

## Objetivo
Reduzir latência e suportar experiências degradadas sem transformar o desktop em banco principal.

## Pode ficar local
Preferências de UI, cache de recursos, rascunhos explicitamente definidos e dados temporários.

## Deve permanecer no servidor
Conta, permissões, assinatura, histórico oficial, memória sincronizada e dados críticos.

## Expiração
Todo cache deve ter política de TTL ou invalidação.

## Logout
Limpar ou invalidar dados locais sensíveis associados à sessão.
