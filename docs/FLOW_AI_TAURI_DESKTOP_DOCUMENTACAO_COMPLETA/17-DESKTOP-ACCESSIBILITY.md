# Acessibilidade

## Requisitos
Teclado completo, foco visível, labels, semântica, contraste, tamanho de texto e compatibilidade com tecnologias assistivas.

## Voz
Não depender exclusivamente de voz. Toda ação essencial deve possuir alternativa visual/teclado.

## Erros
Mensagens devem explicar problema e ação possível.

## Testes
Incluir navegação somente por teclado e testes com leitores de tela nas plataformas prioritárias.
