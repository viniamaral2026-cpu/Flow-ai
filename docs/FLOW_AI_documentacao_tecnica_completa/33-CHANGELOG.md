# FLOW AI — CHANGELOG

## Formato
Cada versão deve registrar:

- data;
- versão;
- mudanças;
- correções;
- migrations;
- alterações de API;
- alterações de infraestrutura;
- riscos;
- rollback.

## 0.x — Fundação
Arquitetura, documentação, mapa de telas e contratos iniciais.

## Próximas versões
Use este arquivo como registro cronológico. Não declarar funcionalidades como concluídas sem validação no código/ambiente.

## Regra de API
Mudanças incompatíveis devem aparecer claramente e indicar migração.

## Regra de banco
Migrations e alterações de dados devem ser descritas.

## Regra de infraestrutura
Mudanças em DNS, Cloudflare, Firebase, NVIDIA, Meta ou secrets devem ser registradas sem incluir valores secretos.
