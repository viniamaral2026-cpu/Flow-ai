## Fluxos críticos

### Autenticação
Login → verificação → onboarding → dashboard.

### Chat
Nova conversa → mensagem → resposta → ferramenta → confirmação → execução → resultado.

### Rotina
Lista → criar → gatilho → condição → ações → teste → ativar.

### Integração
Catálogo → detalhe → OAuth → callback → conectada → configuração.

### Assinatura
Planos → seleção → checkout → pagamento → assinatura.

### Segurança
Conta → segurança → 2FA/sessões → confirmação.

## Navegação
Toda ação destrutiva exige confirmação apropriada.
