# FLOW AI — PRIVACIDADE, LGPD E GOVERNANÇA

## Objetivo
Definir controles técnicos para proteção de dados pessoais.

## Categorias
- cadastro;
- autenticação;
- conversas;
- memória;
- voz;
- arquivos;
- integrações;
- cobrança;
- notificações;
- logs.

## Princípios técnicos
- minimização;
- finalidade;
- necessidade;
- acesso restrito;
- retenção;
- exclusão;
- rastreabilidade.

## Direitos
O produto deve possuir fluxos para atender solicitações compatíveis com os direitos previstos na legislação aplicável.

## Exportação
Gerar arquivo protegido e temporário.

## Exclusão
Executar exclusão/anonimização conforme política e obrigações legais.

## Consentimentos
Registrar versão, finalidade e timestamp quando necessário.

## Logs
Nunca armazenar senha, API key ou token.

## Base legal
A definição jurídica da base legal deve ser feita pelo responsável jurídico da empresa.

## DPA
Quando houver operadores/suboperadores, contratos e responsabilidades devem ser documentados.
