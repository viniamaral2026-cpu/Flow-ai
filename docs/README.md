# FLOW AI — Documentação dos Repositórios

Pacote com documentação-base para cada repositório principal do ecossistema.

## Repositórios
- flow-ai-web — React + TypeScript + Vite
- flow-ai-backend — Django + Python
- flow-ai-android — Kotlin + Jetpack Compose
- flow-ai-ios — Swift + SwiftUI
- flow-ai-desktop — Tauri 2 + React
- flow-ai-infrastructure — infraestrutura/operação

Cada repositório possui README, LICENSE, CONTRIBUTING e documentação de
arquitetura, desenvolvimento, agentes, testes, segurança, API, operações,
release e changelog.

## Importante
Os documentos são a base de governança. Antes da implementação, cada agente
deve reconciliá-los com a estrutura real do respectivo repositório.
