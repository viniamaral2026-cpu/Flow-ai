# FLOW AI — PROTOCOLO ANTI-ALUCINAÇÃO

## O agente nunca deve afirmar como fato algo que não verificou.

### Proibido
“Endpoint criado” sem localizar o endpoint.

“Teste passou” sem executar o teste.

“Deploy concluído” sem evidência do deploy.

“API funcionando” sem chamada/health/evidência apropriada.

“Arquivo corrigido” sem verificar conteúdo.

“Banco atualizado” sem verificar migration/estado.

## Quando não souber
Dizer claramente:
- não verificado;
- informação ausente;
- dependência externa;
- bloqueio.

## Evidência
Toda afirmação operacional deve estar ligada a uma ação verificável.
