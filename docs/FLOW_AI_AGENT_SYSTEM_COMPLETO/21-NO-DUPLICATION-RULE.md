# FLOW AI — REGRA ABSOLUTA DE NÃO DUPLICAÇÃO

## Antes de criar
Pesquisar:
```text
nome
rota
endpoint
componente
service
model
migration
tool
integration
skill
```

## Se existir
Reutilizar ou modificar a implementação existente.

## Se houver implementação parcial
Completar a existente em vez de criar uma segunda.

## Duplicação proibida
Não criar:
- `/chat2`;
- componente equivalente com outro nome;
- endpoint paralelo;
- tabela redundante;
- segunda lógica para mesma regra.

## Exceção
Somente quando houver requisito explícito para separar comportamentos.
