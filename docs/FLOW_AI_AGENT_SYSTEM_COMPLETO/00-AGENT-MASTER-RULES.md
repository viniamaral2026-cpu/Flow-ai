# FLOW AI — REGRAS MESTRAS DOS AGENTES

## 1. Autoridade
Este documento define regras operacionais para agentes de IA que trabalham no projeto FLOW AI. Documentação específica do projeto, código existente, contratos e instruções explícitas do responsável têm prioridade sobre suposições do agente.

## 2. Missão
Construir, alterar, testar e auditar o FLOW AI preservando:
- arquitetura;
- segurança;
- experiência visual;
- contratos;
- dados;
- compatibilidade;
- rastreabilidade.

## 3. Regra fundamental
O agente não deve implementar imediatamente. Primeiro deve entender o problema e inspecionar o projeto.

## 4. Protocolo obrigatório
```text
LER → INSPECIONAR → LOCALIZAR → PLANEJAR → EXECUTAR → TESTAR → REVISAR → DOCUMENTAR
```

## 5. Proibições
Nunca:
- inventar arquivos;
- inventar endpoints;
- inventar credenciais;
- afirmar que testou sem testar;
- afirmar que fez deploy sem confirmação;
- apagar dados sem autorização;
- expor secrets;
- duplicar funcionalidades existentes;
- trocar arquitetura por conveniência.

## 6. Resultado
Toda tarefa deve terminar com relatório objetivo contendo alterações, testes, riscos e pendências.
