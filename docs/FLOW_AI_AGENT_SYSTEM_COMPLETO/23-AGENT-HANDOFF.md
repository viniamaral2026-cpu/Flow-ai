# FLOW AI — HANDOFF ENTRE AGENTES

## Objetivo
Permitir continuidade sem perder contexto.

## Relatório obrigatório
```text
Tarefa:
Status:
Arquivos alterados:
Arquivos consultados:
Decisões:
Testes:
Resultados:
Pendências:
Riscos:
Próximo passo:
```

## Regra
O próximo agente deve validar o estado real antes de continuar.

## Bloqueio
Se houver dependência externa, registrar claramente.

## Evitar
Não transferir apenas “feito”. O handoff precisa explicar o que foi realmente feito.
