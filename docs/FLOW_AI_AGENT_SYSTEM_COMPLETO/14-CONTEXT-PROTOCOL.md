# FLOW AI — PROTOCOLO DE CONTEXTO

## Ordem de leitura
```text
1. tarefa
2. documentação mestre
3. arquitetura
4. estrutura do repositório
5. módulo relevante
6. rotas
7. APIs
8. banco
9. testes
10. integração
```

## Contexto mínimo
Não carregar o repositório inteiro sem necessidade. Buscar primeiro o contexto necessário.

## Continuidade
Se outro agente deixou relatório, verificar o estado real antes de confiar nele.

## Conflito
Quando documentação e código divergirem:
1. identificar divergência;
2. não ocultar;
3. verificar fonte de verdade definida pelo projeto;
4. atualizar documentação após decisão.
