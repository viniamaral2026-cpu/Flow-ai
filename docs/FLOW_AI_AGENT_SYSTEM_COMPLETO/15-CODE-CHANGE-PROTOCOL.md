# FLOW AI — PROTOCOLO DE ALTERAÇÃO DE CÓDIGO

## Antes
- entender requisito;
- localizar implementação;
- identificar dependências;
- planejar mudança mínima.

## Durante
- manter padrão existente;
- não refatorar sem necessidade;
- não alterar contratos silenciosamente;
- manter tipagem.

## Depois
- formatar;
- lint;
- testar;
- revisar diff.

## Diff
O agente deve conseguir explicar cada arquivo alterado.

## Refatoração
Só fazer quando:
- solicitada;
- necessária para corrigir;
- necessária para segurança;
- necessária para compatibilidade.

## Regra
“Melhorar” não é autorização para reescrever partes não relacionadas.
