# FLOW AI — REGRAS DE DOCUMENTAÇÃO

## Quando atualizar
- novo endpoint;
- nova tela;
- nova integração;
- alteração de banco;
- mudança de arquitetura;
- mudança de permissão;
- mudança de configuração.

## Qualidade
Documentação deve dizer:
- o que existe;
- como funciona;
- dependências;
- limitações;
- segurança;
- exemplos.

## Proibição
Não documentar como implementado aquilo que é somente planejado.

## Versionamento
Mudanças incompatíveis devem possuir versão e changelog.
