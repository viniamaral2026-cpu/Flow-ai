# FLOW AI — GIT RULES

## Branch
Alterações relevantes devem ser isoladas em branch apropriada conforme política do projeto.

## Commit
Mensagens devem descrever a mudança.

## Pull Request
Deve conter:
- objetivo;
- alterações;
- testes;
- riscos;
- migration;
- screenshots quando UI.

## Não fazer
- commit de secrets;
- force push destrutivo sem autorização;
- alterar arquivos não relacionados;
- esconder falhas nos testes.

## Merge
Somente após validação dos checks exigidos.
